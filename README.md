# Wanderlust 🏡

A full-stack web application inspired by Airbnb, where users can explore property listings, create listings, upload images, and manage reviews.

## 🔗 Live Demo

[**View Wanderlust Live**](https://wanderlust-11tx.onrender.com/listings)

## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- EJS
- JavaScript
- CSS
- Passport.js
- Cloudinary

## ✨ Features

- User authentication and authorization
- Create, edit, and delete property listings
- Upload listing images
- Add and manage reviews
- MongoDB database integration
